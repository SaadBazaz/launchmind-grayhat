# Module 05 — Marketing Agent

## Goal

Read product spec, generate all marketing copy via LLM, send cold outreach email via SendGrid, post Block Kit Slack message, return all copy to CEO.

## File

`agents/marketing_agent.py`

## Inputs

- Product spec JSON (from message bus, sent by Product agent)
- PR URL (from message bus, forwarded by CEO after Engineer completes)

## LLM Call — Full Copy Generation

**System prompt:** You are a growth marketer for an early-stage startup. Given a product spec, generate marketing copy as valid JSON matching the schema below. Be creative and specific to the product — do not use generic filler.

**Schema:**
```json
{
  "tagline": "under 10 words",
  "landing_description": "2-3 sentence product description for a landing page",
  "cold_email": {
    "subject": "string",
    "body": "string (plain text, 150-200 words, includes clear CTA)"
  },
  "social_posts": {
    "twitter": "string (under 280 chars, includes relevant hashtags)",
    "linkedin": "string (professional tone, 2-3 sentences)",
    "instagram": "string (casual tone, emoji ok, includes hashtags)"
  }
}
```

**User prompt:** Serialised product spec.

## Email Flow (SendGrid)

```python
from sendgrid import SendGridAPIClient
from sendgrid.helpers.mail import Mail

# subject and body come from LLM output — never hardcoded
# to_email = os.environ["EMAIL_TO"]
# from_email = os.environ["SENDGRID_FROM_EMAIL"]
```

- Send cold_email.body as HTML (`<p>` wrapped) to `EMAIL_TO`.
- Log HTTP status code from SendGrid response.

## Slack Flow (Block Kit)

Post to `SLACK_CHANNEL` using `chat.postMessage`:

```json
{
  "blocks": [
    { "type": "header", "text": { "type": "plain_text", "text": "🚀 New Launch: {tagline}" } },
    { "type": "section", "text": { "type": "mrkdwn", "text": "{landing_description}" } },
    {
      "type": "section",
      "fields": [
        { "type": "mrkdwn", "text": "*GitHub PR:* <{pr_url}|View PR>" },
        { "type": "mrkdwn", "text": "*Status:* Ready for review" }
      ]
    }
  ]
}
```

- `SLACK_BOT_TOKEN` from env.
- PR URL must be present before this call — CEO must forward it first.

## Outputs (via message bus)

```
send(marketing → ceo, result, payload={
  "tagline": "...",
  "landing_description": "...",
  "cold_email": { "subject": "...", "body": "..." },
  "social_posts": { "twitter": "...", "linkedin": "...", "instagram": "..." },
  "email_sent_to": "...",
  "slack_posted": true
})
```

## Constraints

- `SLACK_BOT_TOKEN`, `SENDGRID_API_KEY`, `SENDGRID_FROM_EMAIL`, `EMAIL_TO` all from env.
- Slack message must use Block Kit — plain text is not acceptable per spec.
- Email subject and body generated by LLM — never hardcoded.
